# PerGram Go

Scan or type a grocery shelf price, and see whether it's good, meh, or bad against a price you set.

[App Store (Canada)](https://apps.apple.com/ca/app/pergram-go/id6799463251) · [Website](https://asarmichil.com/pergram)

Built with Swift, SwiftUI, SwiftData and Vision, with Claude Code. No backend or third-party packages.

Open `pergram.xcodeproj` in Xcode to build. Requires iOS 26.5+.
